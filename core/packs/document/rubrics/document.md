# Rubric: document

A verifier reads one document unit and answers each item pass or fail, with the
line that shows it. Items the mechanical checks already enforce are restated so
the verifier can judge what they cannot: meaning and fit.

1. Purpose. The summary states what the document is for and who it is for, in
   the first paragraph.
2. Sections. Each declared section has content that answers its heading, not
   only the heading.
3. Claims. Every number in the results is attributed to a method described in
   the document. A figure with no method behind it fails.
4. Scope. The limitations section names what the document does not show.
5. Placeholders. No text reads as unfinished, even when no marker matches the
   placeholder check (for example "the figure goes here").
6. Length. The text fits its declared pages without padding: repeated sentences
   and filler paragraphs fail even when the word count passes.

Verdict: pass when all six items pass. Otherwise fail, naming the items.
